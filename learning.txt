users

Field	Type	Connects to / Notes
_id	ObjectId	referenced by connectedaccounts.userId and posts.userId
fullName	String	
email	String	unique
password	String	only for authProvider: 'local'
authProvider	String	'local' | 'google'
googleId	String	only for authProvider: 'google'
picture	String	avatar (Google photo, or future local upload)
createdAt / updatedAt	Date	auto

connectedaccounts

Field	Type	Connects to / Notes
_id	ObjectId	referenced by posts.targets[].connectedAccountId
userId	ObjectId	→ users._id
platform	String	'youtube' | 'instagram' | 'linkedin'
accountLabel	String	user's own nickname
platformUserId	String	ID from that platform
platformUsername	String	handle/display name
platformAvatarUrl	String	real profile photo from platform API
accessToken / refreshToken	String	encrypted
tokenExpiresAt	Date	
status	String	'active' | 'expired' | 'revoked'
createdAt / updatedAt	Date	auto

posts

Field	Type	Connects to / Notes
_id	ObjectId	
userId	ObjectId	→ users._id
postType	String	'text' | 'image' | 'video'
targets[].connectedAccountId	ObjectId	→ connectedaccounts._id (one row per selected account)
targets[].platform	String	copied from that account
targets[].status	String	'pending' | 'posted' | 'failed'
targets[].platformPostId	String	ID returned by that platform after posting
targets[].postedAt	Date	
targets[].errorMessage	String	
caption	String	Main Caption
platformCaptions.youtube/instagram/linkedin	String	only set if that platform was edited
media[].url	String	Cloudinary URL
media[].type	String	'image' | 'video'
media[].order	Number	carousel order
youtube.title	String	only when a YouTube target + video format
youtube.thumbnailUrl	String	Cloudinary URL
scheduledAt	Date	null = Publish Now
timezone	String	
status	String	'draft' | 'scheduled' | 'publishing' | 'posted' | 'partially_failed' | 'failed'
lockedAt	Date	set while publishing, blocks edits
createdAt / updatedAt	Date	auto

Relationships

users (1) ──< connectedaccounts (many)
users (1) ──< posts (many)
connectedaccounts (1) ──< posts.targets (many)
